🎮 Hangman Game

A simple **console-based Hangman Game** developed using Python as part of my **CodeAlpha Python Internship – Task 1**.

📌 About the Project

The computer randomly selects one word from a list of 5 predefined words. The player has to guess the word one letter at a time.

The player is allowed a maximum of **6 incorrect guesses**.

🛠️ Concepts Used

* Python Lists
* Strings
* Random Module
* `while` loop
* `for` loop
* `if-else` conditions
* User Input
* Console Input/Output

🎯 How the Game Works

1. The program stores 5 predefined words.
2. A word is selected randomly.
3. The selected word is displayed as blanks.
4. The player enters one letter at a time.
5. Correct letters are revealed.
6. Incorrect guesses are counted.
7. The player wins by completing the word.
8. The game ends after 6 incorrect guesses.

And then run the program to fill the words as we give the above coding.
